## Опис проєкту
Проєкт присвячений розробці **ML-рішення для прогнозування відтоку клієнтів (Customer Churn)** у телекомунікаційній компанії.

Метою є визначення клієнтів з високою ймовірністю відтоку, щоб компанія могла завчасно застосувати **retention-стратегії** (знижки, персональні пропозиції, покращення сервісу тощо).

Проєкт реалізований у **Python**, має інтерактивний вебінтерфейс на **Streamlit** та розгортається за допомогою **Docker**.

---

## Постановка задачі
Розв’язується задача **прогнозування відтоку клієнтів**.

- **Тип задачі:** бінарна класифікація  
- **Цільова змінна:** `churn`  
  - `1` — клієнт піде  
  - `0` — клієнт залишиться  

---

## 📊 Дані
Використовуються історичні дані клієнтів телекомунікаційної компанії, що містять інформацію про:
- контрактні умови,
- підключені послуги,
- платіжну поведінку,
- користування сервісами.
